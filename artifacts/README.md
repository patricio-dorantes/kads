# KADS artifact space

This directory is reserved for artifacts created for KADS itself, such as original diagram sources or teaching fixtures. It is for contributors to KADS; adopters do not need it. It currently holds nothing. No operational outputs, copied datasets, review bundles, or records from evaluated projects belong here.

The catalog currently has no stored artifacts. Examples can keep small fictional fixtures inline, as in the [illustrative research report](../examples/research-report/README.md), without creating a duplicate file.

For a future KADS artifact, identify its purpose, canonical location, role, relevant version, and interpretation limits. Use the [artifact guide](../docs/artifact-guide.md), [entry outline](../templates/artifact.md), or [bundle outline](../templates/artifact-bundle.md) only when useful.

Projects applying the standard maintain their own technical artifacts in their own native homes. Guidance about an artifact is not a reason to copy that artifact into KADS.
