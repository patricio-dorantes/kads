None of these works endorses KADS. Each row says where KADS uses the work, how its link answered when checked, and, in the last column, whether the cited passage was inspected for the claim it supports (clause 3.1).

## How to add a source

Cite the specific passage, version, or section a claim relies on (clause 3.1). Add the work here with the place it is used, record an access check with its date, and say whether the passage was inspected for the claim (clause 3.1). If the work is behind a paywall or blocks automated requests, say so rather than omitting the citation (clause 6.3). Scholarly sources supporting a concept remain distinct from any evaluated project's records.

## About this page

Most works were cited by the drafting agent from prior knowledge: the link was checked, but the text was not opened and read for the claim it supports. Those rows say so. Where a passage was inspected, the row says which, when, and by what. An automated fact check is automated review, not verification by a person. "Restricted" means the publisher refused an automated request, not that the work is unavailable. Each link was requested on 2026-10-02 or 2026-10-03 from the authoring environment; re-check when a link is reported broken or at each minor release. Citations of these works elsewhere in KADS rely on this page for that identification.
