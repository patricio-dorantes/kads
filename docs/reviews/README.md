# Reviews of the standard

This directory holds dated notes of feedback received on KADS and what was done with each. It is for readers who want to inspect the basis of a version of KADS. The notes are history, not rules; the rules are in the [specification](../specification.md).

| Date | Note | Resulting version |
|---|---|---|
| 2026-10-02 | [Adoption feedback on evidence handling and negative results](2026-10-02-adoption-feedback.md) | 0.5.0 |
| 2026-10-03 | [Standards evaluation: 31 candidate principles from external standards](../../decisions/standards/README.md), kept under `decisions/standards/` because each candidate has its own record | 0.6.0 |
| 2026-10-03 | [Decision and readiness assurance](../../decisions/assurance/README.md): 22 candidates, one record | 0.7.0 |
| 2026-10-03 | [The maintainer's reading of 0.7.0](../../decisions/self-explanation/README.md): the entry path, identifiers, and documents that did not explain themselves | 0.8.0 |

A note keeps generalized findings and dispositions only. Under the boundary in [Contributing](../../CONTRIBUTING.md), it does not reproduce an adopting project's documents, record identifiers, paths, or environment details.

No such note exists for the 0.3.0 revision; that gap is described in the [evaluation of the standard](../standard-evaluation.md).
