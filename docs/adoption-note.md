# KADS applied to this repository

This page is the adoption note of the KADS repository itself: the declaration, required by clause 8.1 of the [specification](specification.md), of which version of KADS these documents follow, which documents are covered, and who reviewed them. It doubles as a filled-in example of the outline in the [adoption guide](adoption-guide.md). If you are adopting KADS in your own project, read that guide; this page describes only this repository.

| Field | Value |
|---|---|
| Adoption note version | None of its own. This note is identified by the KADS version and tag in the Standard row, which is the repository's own release (clause 8.4). |
| Standard | KADS 0.9.0, tag `v0.9.0`, this repository |
| Covered corpus | `README.md`, `CHANGELOG.md`, `CONTRIBUTING.md`, `docs/`, `registry/`, `templates/`, `examples/`, `artifacts/`, `decisions/` |

External works: `docs/sources.md`. Design rationale: `docs/foundations.md` and `docs/adr/`. Reviews of the standard: `docs/reviews/`. Evaluated candidate principles, including rejected ones: `decisions/`. |

| Run identity | Review evidence is kept in bundles under `decisions/*/evidence/`, each named by date and a sequence number that is never reused, with a manifest giving its collection and limits. |
| Redaction records | Each evidence bundle's manifest records its alterations, such as replaced machine paths. The one known removal from other content, of identifying detail from adoption feedback, is described in the [review note](reviews/2026-10-02-adoption-feedback.md). |
| Freshness checks | None needed: no generated views. Version statements derived from `VERSION` are checked by hand at release, as listed in [Contributing](../CONTRIBUTING.md). |
| Maintainer or review route | The repository maintainer, through merge requests on the hosting Git service, as described in [Contributing](../CONTRIBUTING.md). |
| Review triggers | Any version change; a reported broken link or ambiguous clause; feedback from an adopting project; a change to a cited source. |
| Local extensions | None. |
| Exceptions | None declared. One known evidence gap, not an exception: the review that shaped 0.3.0 was not preserved; see the [evaluation of the standard](standard-evaluation.md). |
